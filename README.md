# Signal Monitor

An Android app for monitoring mobile network signal quality in real time.

## Features

- Live signal strength, latency, and speed tracking
- Time-series charts and historical data
- Map view of signal measurements
- Network Quality Score (NQS) algorithm
- CSV export
- Background monitoring service with boot persistence
